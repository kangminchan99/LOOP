# BLE 기기 스캔 기능

## 기능 목적

앱에서 주변 BLE 기기를 탐색하고, 기기 목록과 연결 상태를 보여준다.

초기 단계에서는 실제 BLE 기기가 없어도 개발할 수 있도록 mock 기기 목록으로 화면과 상태관리를 먼저 구현한다.

## BLE 의미

BLE는 Bluetooth Low Energy의 약자다.

저전력 블루투스이며, 비콘, 센서, 스마트밴드, IoT 기기처럼 짧은 데이터를 적은 배터리로 주고받는 기기에서 많이 사용된다.

## 첫 번째 구현 범위

```txt
1. BLE 스캔 화면
2. 스캔 시작 / 중지
3. mock BLE 기기 목록 표시
4. 기기 연결 / 연결 해제 UI
5. 연결 상태 표시
```
